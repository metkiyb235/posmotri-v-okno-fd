# Проект «Посмотри в окно» — Стилизация интерфейса

Фронтенд-приложение интерфейса видеотрансляций из разных городов. Проект выполнен в рамках адаптации макета под строгие визуальные требования гайдлайнов и pixel-perfect соответствия.

## 📌 Цель работы
Все ключевые файлы (`index.html`, шаблоны, базовые скрипты и файлы ошибок) были **предоставлены изначально**. Основная задача заключалась в глубокой отладке, рефакторинге и кастомизации стилей в файле **`style.css`** (и сопутствующих CSS-модулях) для исправления багов верстки и достижения полного соответствия дизайн-макету.

## 🛠 Какие задачи были решены в `style.css`:
1. **Кастомизация элементов форм и чекбоксов**:
   * Успешно переработаны стандартные элементы форм: инпуты и кнопки приведены к строгому стилю макета.
   * Полностью скрыты системные чекбоксы и созданы стильные кастомные индикаторы с помощью псевдоэлементов (`.search-form__pseudo-checkbox::after`), которые плавно реагируют на выбор пользователя.

2. **Точное позиционирование оверлея ошибки (`.error`)**:
   * Настроено правильное поведение контекста позиционирования для блока «Нет подходящих видео / Из этого города нет видео».
   * Элемент `.error` теперь идеально накладывается поверх контейнера видеоплеера `.result__video-container` (строго в границах `711 × 386 px`) без необходимости изменять исходную HTML-структуру.


3. **Оптимизация UX и интерактивных состояний**:
   * Написаны стили для поведения кнопок при наведении (`:hover`), фокусе и нажатии (`:active`), включая изменение цвета фона на фирменный акцентный оттенок `#545050`.
   * Добавлен аккуратный кастомный скроллбар для контейнера со списком городов.

## 💻 Технологический стек
* HTML5 (исходная семантическая разметка и `<template>`)
* CSS3 (Flexbox, CSS Grid, позиционирование, кастомные свойства, кастомизация форм)
* Native JavaScript (изначальный скрипт управления логикой)

## 🚀 Как запустить проект
1. Склонируйте репозиторий или скачайте архив с проектом.
2. Откройте файл `index.html` в любом современном браузере.
